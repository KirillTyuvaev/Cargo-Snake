# Snake Game - Веб-версия

Классическая игра "Змейка", написанная на JavaScript. Игра работает прямо в браузере, без необходимости установки дополнительного ПО.

## Как играть

1. Откройте [игру онлайн](https://your-username.github.io/snake-game/)
2. Нажмите кнопку "Начать игру"
3. Управляйте змейкой с помощью стрелок на клавиатуре
4. Собирайте красные квадратики (еду) для увеличения длины змейки и набора очков
5. Избегайте столкновений со стенами и собственным телом

## Управление

- Стрелки вверх/вниз/влево/вправо - управление змейкой
- Кнопка "Пауза" - поставить игру на паузу
- Кнопка "Начать игру" - начать новую игру

## Особенности

- Адаптивный дизайн
- Подсчет очков
- Возможность паузы
- Приятная цветовая схема
- Простое управление

## Технические детали

Игра написана на чистом JavaScript с использованием HTML5 Canvas. Не требует установки дополнительных библиотек или плагинов.
